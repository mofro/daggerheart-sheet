# Attribution

This plugin is built on [Wayfinder](https://github.com/alas-poor-ophelia/wayfinder)
by alas, poor ophelia, released under the MIT License.

The Obsidian plugin architecture, Preact+signals reactive UI patterns, build
system (esbuild + Sass), sidebar/tab layout, `data.json` storage model, and
rules-note-linking infrastructure are derived from that work.

All Pathfinder 1st Edition domain content (class data, race data, spell
database, equipment catalog, calc modules) has been removed. The Daggerheart
character model, calc layer, and UI are new work.
